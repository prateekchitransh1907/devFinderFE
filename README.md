# devFinderFE

A modern web application for developers to connect, collaborate, and manage their professional network.

## Features

- User authentication (login & signup)
- View and edit user profiles
- Personalized user feed
- Manage connections and requests
- Responsive and intuitive UI

## Technologies Used

- React
- Vite
- Redux (if used)
- Tailwind CSS & daisyUI
- Node.js (v22.12+ recommended)

## Getting Started

### Prerequisites

- Node.js v22.12.0 or higher (use [nvm](https://github.com/nvm-sh/nvm) for easy management)
- npm or yarn

### Installation

```bash
git clone https://github.com/yourusername/devFinderFE.git
cd devFinderFE
npm install
```
